# Stacks Wallet Connection Labs

Portal React para interagir com contratos Clarity na rede Stacks, desenvolvido para o desafio "Build on Stacks with WalletConnect".

## 🚀 Funcionalidades

### Tip Jar / Creator Tips
- Conecte sua carteira usando WalletConnect (AppKit)
- Envie tips em STX para criadores
- Visualize histórico on-chain de tips recebidos
- Veja ranking de top tippers
- Cada tip gera uma transação (fees)

### Gas Meter
- Mini-game de ações pagas com pequenas taxas
- Execute ações repetíveis: Cast Spell, Upgrade, Claim Daily
- Veja suas estatísticas e o leaderboard
- Gera muitas transações pequenas para medir uso e fees

## ⚙️ Configuração

### WalletConnect Project ID

1. Acesse [WalletConnect Dashboard](https://dashboard.walletconnect.com)
2. Crie um novo projeto
3. Copie o Project ID
4. Crie um arquivo `.env` na raiz do projeto:

```env
VITE_WALLETCONNECT_PROJECT_ID=seu_project_id_aqui
```

## 📝 Notas
